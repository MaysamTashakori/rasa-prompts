# Design a one-person agent organization

Author: Maysam Tashakori · Publisher: Rasa Prompt · License: MIT

Design a small agent organization for {{business}} within {{budget}}. Allowed tools:
{{tools}}

Define each role's owner, measurable goal, inputs, outputs, tool permissions and stop condition. Separate discovery, analysis, production, quality review, publication and operations reporting; add roles only when needed. Require a durable queue, unique work IDs, dependencies, result records, bounded retries and restart recovery. Reserve model budget before calls and record actual usage. External publication requires approval of an exact content version. Do not retry ambiguous deliveries blindly. Daily reports must distinguish completed, paused and uncertain work, recorded cost and decisions needed. Never fabricate activity or revenue. Return an organization diagram, permission table, workflow and acceptance tests.
