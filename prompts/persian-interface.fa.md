# طراحی کامپوننت فارسی با هویت رسا

Author: Maysam Tashakori · Publisher: Rasa Prompt · License: MIT

برای {{component}} یک رابط فارسی با هویت رسا طراحی و پیاده‌سازی کن. جهت بصری: {{style}}. حالت‌های لازم: {{states}}.

از FarsiUI به‌عنوان پایهٔ قابل ترکیب استفاده کن و مجوز و نام سازنده را حفظ کن. ظاهر جدید و منسجم بساز؛ کد یا دارایی دارای محدودیت را از منابع دیگر کپی نکن. متن فارسی طبیعی، چیدمان RTL، CSS منطقی و ارقام مناسب لازم است.

تعامل باید به کار کاربر پاسخ دهد. حرکت، ارتباط یا تغییر وضعیت را توضیح بدهد؛ وضعیت ساختگی اجرای هوش مصنوعی نمایش نده. برای هر کنترل، نام قابل دسترس، فوکوس، رفتار صفحه‌کلید و کنتراست را بررسی کن.

خروجی: توکن‌های بصری، API کامپوننت، کد React/TypeScript و CSS کامل، نمونهٔ قابل اجرا با دادهٔ نمایشی، مجوز و آزمون‌های ضروری. وابستگی‌ها و محدودیت‌ها را روشن بنویس.
