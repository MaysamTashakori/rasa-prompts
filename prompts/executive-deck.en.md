# Interactive executive presentation

Author: Maysam Tashakori · Publisher: Rasa Prompt · License: MIT

Design a decision-focused presentation about {{topic}} for {{audience}}. Permitted evidence:
{{evidence}}

Organize eight 16:9 slides: problem, significance, evidence, alternatives, comparison, recommendation, execution and requested decision. Give every slide one takeaway, a clear title, a data-grounded visual and brief speaker notes. Never invent missing figures. Attach sources to the claims they support. Specify keyboard navigation, slide overview, fullscreen, optional chart details and clean printing. Use readable Persian RTL when appropriate. Motion should explain relationships or state changes; include reduced-motion and mobile layouts. Return a slide-by-slide narrative, visual specifications, required data, interactions, speaker notes and a preflight checklist. Separate assumptions and approval needs.
