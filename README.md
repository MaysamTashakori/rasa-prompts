# Rasa Prompts | پرامپت‌های رسا

Original Persian and English prompts by **Maysam Tashakori**, published as **Rasa Prompt**. MIT licensed.

هفت پرامپت تألیفی برای گزارش تصمیم‌ساز، ارائه، طراحی محصول و فرایندهای مرتبط. متن فارسی و انگلیسی هر پرامپت در پوشهٔ prompts قرار دارد. متغیرهای {{name}} را با ورودی خود جایگزین کنید؛ فایل prompts.json مشخصات فرم و مقادیر پیش‌فرض را دارد.

These are reusable instructions, not an agent runtime or a hosted model. Do not insert credentials or private information into third-party services. Do not treat generated text as verified evidence.
